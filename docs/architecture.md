# 拼省省系统架构

## 服务职责

| 服务 | 默认端口 | 当前职责 |
|---|---:|---|
| Gateway | 8380 | 统一入口、路由和跨域 |
| Auth | 8382 | 登录、令牌和用户身份 |
| Product | 8381 | 商品、分类、SKU 和商品详情 |
| Cart | 8383 | 购物车和购物车选中状态 |
| Order | 8384 | 地址、结算、订单和订单明细 |
| Payment | - | 由订单服务提供模拟支付 |
| Frontend | 5173 | Vue 3 用户端 |

基础设施：MySQL `13380`、Redis `16379`、Nacos `8848`、RabbitMQ `5672`、MinIO `9000`。

## 业务主链路

```text
用户登录 -> 浏览商品 -> 商品详情 -> 加入购物车
    -> 结算 -> 锁定库存 -> 创建订单 -> RabbitMQ 异步清理购物车 -> 模拟支付
```

订单事务提交成功后，Order 服务发布 `order.created` 消息，Cart 服务消费消息并删除已经购买的 SKU。前端即时删除作为体验优化，消息消费作为服务端兜底。
